## 지표 정의 및 측정 범위

- Recall@k: 상위 k개 청크에서 찾은 서로 다른 정답 문서 수 / 해당 문항의 정답 문서 수. 65문항의 평균.
- MRR@k: 상위 k개 청크 안에서 처음 나타난 정답 문서의 청크 순위 역수. 없으면 0. 65문항의 평균.
- 전체 순위 MRR: 필터 적용 후 전체 청크 순위에서 첫 정답 순위의 역수 평균. 문서 중복을 제거한 순위가 아님.
- 키워드 포함률: NFC 정규화 및 대소문자 무시 후 정답 키워드의 답변 내 부분문자열 포함 비율을 문항별 계산해 평균. 사실성 평가는 아님.
- 평균 응답 시간: 질문 임베딩 + 검색 + 답변 생성의 실제 경과 시간. SDK 재시도가 있으면 포함. 전처리·인덱스 생성·전체 순위 MRR용 별도 검색·결과 저장은 제외.
- 문항당 k=5에서 1회씩 측정했으므로 API 변동과 제공자 캐시 효과가 포함될 수 있음.
- baseline 소스는 수정하지 않고 별도 평가 스크립트에서 추가 지표를 계산함. 기존 작업 브랜치와 기본 인덱스는 보존함.
